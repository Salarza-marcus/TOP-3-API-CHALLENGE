# Movie Night App

This project is built for the Movies & TV Shows team using the TMDB API.

## Setup

1. Open the local config file `config.js`.
2. Replace the API key if needed with your own TMDB key.
3. Run a local web server in the project folder.



## Notes

- The app fetches live movie data from TMDB using GET requests.
- The key is kept in a local config file instead of being hardcoded directly into the HTML.
- A simple dark-themed layout is used, with a search box and category filter.
